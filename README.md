# 2024-project-phase-mobile-tasks

## Overview

This repository contains the **mobile-task phase** of the 2024 project, focusing on implementing **product management features** using **Dart**. It represents the **logic layer** of a mobile application suitable for Flutter integration, including CRUD operations for products.

## Features

* Add new products with name, description, and price
* View all products or individual product details
* Edit and delete products
* Input validation for price and product selection
* Designed for mobile UI integration

## Mobile Task Relevance

* Demonstrates OOP concepts and data management for mobile apps
* Business logic separated from UI for easy Flutter integration
* Ready for use with Flutter state management (Provider, Bloc, Riverpod)

## Technologies

* Dart
* Compatible with Flutter mobile applications

## Usage

1. Use this logic layer in a Flutter app
2. Replace console input/output with UI components
3. Connect product operations to buttons, forms, and lists

## Purpose

This phase aims to implement the **mobile-specific functionality** for the 2024 project, demonstrating practical Dart programming and CRUD operations for mobile development tasks.
